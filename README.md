# 🤖 NexaAI – AI Technology Website

**NexaAI – Intelligence for Tomorrow** is a modern and responsive AI technology company website designed to showcase artificial intelligence products, services, technologies, and real-world applications.

The website features a futuristic user interface with a dark background, purple gradients, and electric-blue highlights to create a professional technology-focused experience.

## 🌟 Features

- **Modern Navigation Bar** – Easy navigation between website sections.
- **Hero Section** – Introduces NexaAI with an attractive headline and call-to-action buttons.
- **About Us** – Explains the company's mission, vision, and achievements.
- **AI Products & Services** – Showcases AI-powered solutions through interactive cards.
- **AI Applications** – Highlights the use of AI across different industries.
- **Our Technology** – Introduces modern AI technologies and concepts.
- **Why Choose Us** – Highlights the company's strengths and benefits.
- **Our Team** – Displays team members with profile images and social media links.
- **Contact Section** – Provides contact information and a message form.
- **Responsive Design** – Adapts to different screen sizes.
- **Hover Effects** – Adds interactive visual effects to cards and buttons.

## 🎨 Design Highlights

- Futuristic dark-themed interface.
- Purple and electric-blue gradient effects.
- Modern typography and clean layouts.
- Glass-style cards and glowing borders.
- Attractive AI-related images and icons.
- Smooth transitions and hover animations.
- Responsive layouts using CSS Grid and Flexbox.

## 🚀 How to Run the Project

Follow these simple steps:

**1. Clone the repository**

```bash
git clone https://github.com/vasavi2508/Nexa-AI.git
```

**2. Open the project folder**

```bash
cd Nexa-AI
```

**3. Run the website**

Open the `index.html` file in your web browser.

You can also use the **Live Server** extension in Visual Studio Code to preview the website.
